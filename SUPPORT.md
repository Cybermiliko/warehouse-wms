# Support

## Get help

Use the [Warehouse WMS issue tracker](https://github.com/Cybermiliko/warehouse-wms/issues) for:

- Reproducible bugs
- Feature requests
- Installation questions
- Product feedback

Before creating an issue, search existing reports and use the appropriate issue template.

## Include these details

- Platform and operating system version
- Warehouse WMS version
- Steps to reproduce the problem
- Expected and actual behavior
- Screenshots with private inventory details removed

## Keep information private

Do not include passwords, customer information, full inventory exports, certificates, signing files, or other confidential material in a public issue.

Security vulnerabilities should be reported privately through GitHub's security reporting tools when available.
